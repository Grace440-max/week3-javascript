
# Songa Learning Resource Explorer

## About the Project

Songa Learning Resource Explorer is a web application that helps users explore learning resources, search for educational content, filter resources by category, and track their learning progress.

The project was developed using HTML, CSS, and JavaScript.

## Features

Display Resources: Displays learning resources with their titles, categories, descriptions, and completion status.
Search Resources: Allows users to search for resources using keywords.
Category Filtering: Allows users to filter resources by category.
Completion Tracking: Users can mark resources as completed or incomplete.
Progress Tracking: Displays the total number of resources and completed resources.
Responsive Design: Works on desktop, tablet, and mobile screens.

## Technologies Used

- HTML5 – webpage structure.
- CSS3 – styling and responsive design.
- JavaScript – functionality and DOM manipulation.
- Git and GitHub – version control and project hosting.



## How to Use

1. Open the webpage in your browser.
2. Browse the available learning resources.
3. Use the search box to find a resource.
4. Select a category to filter resources.
5. Click the completion button to update your learning status.
